# fineprint 소비자용 프로토타입

[D-008](../docs/decision-log.md)의 두 화면이다.

1. **불리할 수 있는 조건**: 은행마다 금리가 오르는 조건, 중도상환해약금, 연체이자, 한꺼번에 갚아야 하는 경우, 신용점수 영향, 만기 연장 조건을 한 줄씩 요약한다. 줄마다 근거 조항 원문을 펼쳐 볼 수 있다. 끝에 "이 조건들, 이해되셨나요?" 확인을 하나 붙였다(D-008 재검토).
2. **물어보기**: 내 상황을 물으면 에이전트(1.6)가 조항을 찾아 답하고, 근거가 없으면 판단할 수 없다고 말한다. 답의 [1], [2]는 아래 원문 발췌로 이어진다.

**용어 풀이**(D-009 1번): 요약 줄과 답에 나오는 금융 용어 23개에 점선 밑줄을 긋고, 누르면 그 줄 아래에 짧은 풀이와 근거 원문이 열린다. "잘 모르겠는 게 있어요"를 누르면 그 은행 요약에 나온 용어를 모아 보여 준다.

**물어보기로 가는 길**(D-009 2번)
- 요약 줄마다 "근거 원문" 오른쪽 끝에 흐린 "물어보기 →"가 있다(글이 많은 화면이라 눈에 덜 띄게 했다). 누르면 물어보기 탭이 열리고 입력창 위에 그 주제가 표시된다. 입력 안내 문구가 그 주제의 예시로 바뀌고, 관련 예시 질문이 맨 위로 올라온다. 실시간 답변에서는 질문 앞에 주제를 붙여 보낸다. "주제 지우기"로 뺄 수 있다.
- "이 조건들, 이해되셨나요?" 칸 아래의 "물어보기로 가기"는 주제 없이 입력창으로 이동한다.

**입력창 유지**(D-009 3번): 예시 질문을 눌러도 입력창은 그대로 둔다. 답만 아래에 보인다.

- 풀이마다 출처 표시를 단다. **문서 정의**(약관이 직접 정의), **문서 설명**(문서 내용을 풀어 씀), **일반 설명**(문서에 정의가 없어 일반적인 뜻을 씀).
- 근거는 고른 은행 문서를 먼저 보여 주고, 그 은행 문서에 없으면 다른 은행 문서라고 밝히고 보여 준다. 근거 문장 근처만 잘라 보여 준다.
- 풀이 문장은 사람이 근거와 대조해 쓴다(`data/glossary_terms.json`). `scripts/make_glossary.py`가 은행별 근거 조각 id와 문장 위치를 찾아 `data/glossary.json`을 만들고, 근거를 못 찾은 용어가 있으면 실패한다.

## 실행

```powershell
python app/server.py                 # http://localhost:8000, 데모 모드
$env:GEMINI_API_KEY="..."; python app/server.py      # 실시간 답변 (베타, D-010)
```

- 표준 라이브러리만 쓴다. 실시간 답변은 Gemini API 키(`GEMINI_API_KEY`, 무료)로 돌린다. `ANTHROPIC_API_KEY`만 있으면 Claude로 돌린다(`anthropic` 패키지 필요). 문항당 LLM 2번: 초안 → 점검.
- 실시간 답변에는 코드 안전장치([fineprint/guard.py](../fineprint/guard.py))가 걸리고, 화면에 베타 안내와 개인정보 안내가 붙는다. 하루 100개, 한 사람 10분에 5개로 제한한다(`FINEPRINT_DAILY_LIMIT`, `FINEPRINT_IP_LIMIT`).
- 공개 배포는 [render.yaml](../render.yaml)대로 한다. 약관 데이터는 비공개 레포에서 `scripts/get_data.py`로 받는다.
- 조항 원문은 로컬 `data/processed`에서 읽는다. 이 폴더는 레포에 없으므로, 없으면 원문 없이 조항 표기만 보인다(`scripts/parse_terms.py`로 만든다).
- 데모 모드에서는 요약과 예시 질문 13개의 답만 보인다. 예시 답은 1.6 평가에서 고른 것이다.
- "이해되셨나요?" 응답은 `app/feedback.local.jsonl`에 쌓인다(레포에 올리지 않음). 질문 내용은 남기지 않는다.

## 파일

| 파일 | 내용 |
|---|---|
| `ui.html` | 화면 (HTML·CSS·JS 한 파일, 서버와 정적 데모가 같이 씀) |
| `server.py` | 로컬 서버: `/api/state`, `/api/ask`, `/api/feedback` |
| `state.py` | 화면에 줄 데이터 조립 (은행·문서, 요약, 예시 답, 근거 원문) |
| `export_static.py` | 서버 없이 열리는 데모 HTML (`app/dist/`, 원문 포함이라 로컬에만) |
| `data/summaries.json` | 요약 줄과 근거 조각 id (원문 없음) |
| `data/samples.json` | 예시 질문과 답, 근거 조각 id (원문 없음) |
| `data/glossary_terms.json` | 용어, 별칭, 출처 표시, 풀이, 근거 찾는 패턴 (사람이 씀) |
| `data/glossary.json` | 위에 은행별 근거 조각 id와 문장 위치를 붙인 것 (원문 없음) |

요약과 예시 답은 `scripts/make_app_data.py`로 다시 만든다. 요약은 [fineprint/summary.py](../fineprint/summary.py)가 주제별로 검색한 근거 안에서만 LLM이 쓰고, 코드가 근거 번호를 조각으로 되돌린 뒤 고친다. 같은 쪽의 다른 창을 댄 경우, 줄의 숫자가 원문에 없는 경우를 잡는다.

## 아직 안 한 것

- 용어 풀이가 도움이 됐는지는 2차 사용성 테스트(대출 경험자 위주)에서 본다.
- 긴 답을 핵심 2~3문장과 "더 보기"로 나누기(1.6에서 답이 15% 길어졌다).
- 요약 줄의 정확도 평가. 지금은 사람이 근거와 대조해 확인했다.
