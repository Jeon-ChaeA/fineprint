# fineprint 소비자용 프로토타입

[D-008](../docs/decision-log.md)의 두 화면이다.

1. **불리할 수 있는 조건**: 은행마다 금리가 오르는 조건, 중도상환해약금, 연체이자, 한꺼번에 갚아야 하는 경우, 신용점수 영향, 만기 연장 조건을 한 줄씩 요약한다. 줄마다 근거 조항 원문을 펼쳐 볼 수 있다. 끝에 "이 조건들, 이해되셨나요?" 확인을 하나 붙였다(D-008 재검토).
2. **물어보기**: 내 상황을 물으면 에이전트(1.6)가 조항을 찾아 답하고, 근거가 없으면 판단할 수 없다고 말한다. 답의 [1], [2]는 아래 원문 발췌로 이어진다.

## 실행

```powershell
python app/server.py                 # http://localhost:8000, 데모 모드
$env:ANTHROPIC_API_KEY="..."; python app/server.py   # 실시간 답변
```

- 표준 라이브러리만 쓴다. 실시간 답변에만 `anthropic` 패키지와 API 키가 필요하다(문항당 LLM 2번: 초안 → 점검).
- 조항 원문은 로컬 `data/processed`에서 읽는다. 이 폴더는 레포에 없으므로, 없으면 원문 없이 조항 표기만 보인다(`scripts/parse_terms.py`로 만든다).
- 데모 모드에서는 요약과 예시 질문 13개의 답만 보인다. 예시 답은 1.6 평가에서 고른 것이다.
- "이해되셨나요?" 응답은 `app/feedback.local.jsonl`에 쌓인다(레포에 올리지 않음). 질문 내용은 남기지 않는다.

## 파일

| 파일 | 내용 |
|---|---|
| `ui.html` | 화면 (HTML·CSS·JS 한 파일, 서버와 정적 데모가 같이 씀) |
| `server.py` | 로컬 서버: `/api/state`, `/api/ask`, `/api/feedback` |
| `state.py` | 화면에 줄 데이터 조립 (은행·문서, 요약, 예시 답, 근거 원문) |
| `export_static.py` | 서버 없이 열리는 데모 HTML (`app/dist/`, 원문 포함이라 로컬에만) |
| `data/summaries.json` | 요약 줄과 근거 조각 id (원문 없음) |
| `data/samples.json` | 예시 질문과 답, 근거 조각 id (원문 없음) |

요약과 예시 답은 `scripts/make_app_data.py`로 다시 만든다. 요약은 [fineprint/summary.py](../fineprint/summary.py)가 주제별로 검색한 근거 안에서만 LLM이 쓰고, 코드가 근거 번호를 조각으로 되돌린 뒤 고친다. 같은 쪽의 다른 창을 댄 경우, 줄의 숫자가 원문에 없는 경우를 잡는다.

## 아직 안 한 것

- 사용성 테스트. D-008의 "다시 볼 조건": 사람들이 요약만 보고 질문을 하지 않으면 답변 기능의 위치와 형태를 다시 정한다.
- 긴 답을 핵심 2~3문장과 "더 보기"로 나누기(1.6에서 답이 15% 길어졌다).
- 요약 줄의 정확도 평가. 지금은 사람이 근거와 대조해 확인했다.
