# 사용성 테스트 부탁 문구

데모 링크: claude.ai 데모 페이지 주소 끝에 `#test`를 붙여 보낸다(공유 설정을 "링크가 있는 누구나"로 바꾼 뒤).
설문 링크: https://fineprint-survey.netlify.app/usability.html (데모 안의 "설문 답하기" 버튼으로도 간다)

## 1. 개인 메시지 (카카오톡)

```
안녕하세요! 지난번에 약관 설문 도와주셔서 고마웠어요.
그때 모은 답을 바탕으로 "신용대출 약관을 조항 원문으로 읽어 주는" 화면을 처음 만들어 봤어요.

혹시 10분만 써 보고 짧은 설문에 답해 주실 수 있을까요?

👉 (데모 링크)

· 휴대폰으로 열어도 돼요
· 화면 위 안내대로 4가지만 해 보시면 돼요
· 마지막 설문은 3분, 익명이에요
· 이름, 금액, 신용점수 같은 개인정보는 적지 않으셔도 돼요

잘 안 되는 곳이나 헷갈리는 곳을 알려 주시는 게 가장 큰 도움이에요. 고맙습니다!
```

## 2. 리마인드 (사흘 뒤, 한 번만)

```
지난번 부탁드린 fineprint 써 보기, 혹시 아직이시면 이번 주 안에 부탁드려요!
10분이면 끝나요 🙏
(데모 링크)
```

## 주의

- 회사 메신저나 회사 단톡방에는 올리지 않는다.
- 지난 설문에 참여한 사람인지 묻지 않는다(설문은 익명이었다). 문구의 첫 줄은 상대에 맞게 고친다.
- 특정 은행을 고르라고 권하지 않는다. 데모는 금융상품을 권유하지 않는다.
