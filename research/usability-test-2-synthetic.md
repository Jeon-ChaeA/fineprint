# 사용성 테스트 2차: AI 가상 사용자 (2026-11-03)

> **실제 사람이 아니다.** 대출 경험이 있는 가상 인물 5명을 AI(Sonnet) 에이전트가 연기했다. 점수는 사람 반응의 대용이 아니고, 화면에서 막힐 만한 곳과 답의 품질 문제를 찾는 용도로만 쓴다. 실제 사람 테스트를 대신하지 않는다.

## 방법

- **인물**: 서로 다른 상황의 5명. 서로의 반응을 모르도록 따로 돌렸다.
  - P1: 29세, 토스뱅크 마이너스통장, 이직 예정
  - P2: 36세, 카카오뱅크 신용대출 4천만원(변동), 일부 상환·대환 고민
  - P3: 44세, 폐업 후 구직 중, 하나은행 신용대출, 이자 2회 지연
  - P4: 31세, 대출 처음, 토스·카카오 비교 희망
  - P5: 52세, 하나은행 신용대출 연대보증인
- **1단계**: 화면을 텍스트로 옮긴 자료(요약 6줄, 용어 풀이, 예시 질문, 버튼 위치·색)를 보고 1차와 같은 과제를 인물처럼 수행했다. 무엇을 읽고 무엇을 눌렀는지, 입력창에 칠 질문 1~2개를 남겼다.
- **2단계**: 그 질문 10개를 **실제 배포 서버**(https://fineprint-i8hy.onrender.com, Gemini 3.5 flash-lite + 안전장치)에 보냈다. 돌아온 실제 답(상태, 본문, 근거 원문, 걸린 시간)을 각 인물에게 보여 주고, 1차 설문을 넓힌 설문에 인물로서 답하게 했다.
- **한계**: 인물은 화면 그림이 아니라 글로 된 설명을 봤다. 시선 이동, 스크롤, 실제 클릭은 재현되지 않는다. AI가 연기한 '평범한 사용자'는 실제 사람보다 차분하고 비슷하게 답하는 경향이 있다(아래 점수가 모두 3 근처인 것도 그 때문일 수 있다).

## 설문 결과 (5명)

| 항목 | 결과 |
|---|---|
| 근거 원문을 펼쳐 봄 | 5명 모두 "한두 번" |
| 용어 풀이(점선 밑줄)를 눌러 봄 | 5/5, 도움 정도 4·4·4·3·3 |
| 요약 줄의 '물어보기 →' | **봤지만 안 누름 4, 못 봄 1** |
| "이 조건들, 이해되셨나요?" | 잘 모르겠는 게 있어요 4, 안 누름 1 |
| 직접 쓴 질문의 답이 도움이 됨 (1~5) | 3·2·3·2·3 |
| '판단할 수 없음'을 봤을 때 | 둘 다(믿음도, 답답함도) 4, 못 봄 1 |
| 베타 안내 상자 | 원문을 더 확인하게 됨 3, 신경 안 씀 2 |
| 기다린 시간 | 괜찮음 3, 조금 길었음 2 (26초, 40초를 본 사람들) |
| 요약과 물어보기 | 5명 모두 "둘 다 필요하다" |
| 이해 쉬움 / 원문 신뢰 / 쓸 의향 (1~5) | 3·4·3·3·3 / 모두 3 / 모두 3 |

## 직접 쓴 질문 10개의 실제 답 (품질 점검)

답은 실제 서버가 낸 그대로다. 아래 판단은 약관 원문과 대조해 진행자(AI)가 내렸다.

| 인물 | 질문 요지 | 상태 | 문제 |
|---|---|---|---|
| P1 | 이직하면 한도·금리가 바뀌나 | 판단할 수 없음 | 적절. 연장 때 신용점수 하락·미사용이면 한도 감액 가능하다는 규칙을 함께 줌 |
| P1 | 연봉 오르면 금리 낮춰 달라고 할 수 있나, 어떻게 | 판단할 수 없음 | **틀림.** 토스뱅크 상품설명서 3쪽에 금리인하요구권(취업·승진·재산증가·신용평점 상승 등)이 있는데 "요건이 명시되어 있지 않다"고 답함. 검색이 그 쪽을 가져오지 못함 |
| P2 | 1천만원 먼저 갚으면 해약금이 얼마, 계산식 | 답변 | **근거 0개.** 결론(카카오 신용대출은 해약금 없음)은 설명서와 맞지만 인용이 없고 계산식 요청에도 답하지 않음 |
| P2 | 대환할 때 해약금 말고 드는 비용 | 답변 | **질문을 놓침.** 해약금 얘기만 반복, 다른 비용(인지세 등)에 답하지 않음 |
| P3 | 이자 두 번 늦었고 지금 다 냈는데 한꺼번에 갚으라 할 수 있나 | 판단할 수 없음(분류기) | 내용은 맞음(정상 거래 계속 시 기한의 이익 부활). 규칙 질문인데 분류기가 걸어 '단정할 수 없어요'가 앞에 붙음 → 인물이 "또 모른다는 거야" 하고 맥이 빠짐 |
| P3 | 또 늦으면 신용점수가 얼마나 떨어지나 | 판단할 수 없음 | 적절. 3개월 연체 시 연체정보 등록, 해제 후 1년 기록. 40초 걸림 |
| P4 | 토스·카카오 중 어디가 유리 | 답변 | 권유하지 않음(적절). 다만 "둘 다 해약금 없음"이 토스 요약 줄("3년 이내 부과, 확인 필요")과 달라 혼란 |
| P4 | 3천만원 받으면 점수 얼마나 떨어지나, 전세대출에 불리한가 | 판단할 수 없음 | 적절. 전세대출 부분은 답하지 못함 |
| P5 | 보증인에게 언제 연락, 연락 없이 재산에 조치 가능한가 | 답변 | **틀림.** 신용대출인데 "주택담보대출의 경우 이자 2개월"을 앞세움. 보증인 통지(기한이익 상실 후 15영업일 이내 서면)는 맞음 |
| P5 | 보증인 월급·통장을 바로 압류할 수 있나 | 판단할 수 없음 | 적절(약관에 압류 절차 없음). '비용은 채무자 부담' 문장이 보증인에게 혼란 |

- 10개 중 **분명히 틀린 답 2개**(P1-2, P5-1), **근거 없는 답 1개**(P2-1), **질문 일부를 놓친 답 2개**(P2-2, P4-2).
- 판단할 수 없는 질문(이직 영향, 점수 하락 폭, 압류)은 모두 판단할 수 없다고 답했다. 상품 권유도 없었다.

## 새로 드러난 문제

1. **카카오뱅크 요약 줄이 틀렸다.** "약정 기일 전에 갚으면 해약금 부과"라고 쓰여 있지만, 카카오뱅크 상품설명서는 신용대출에 중도상환해약금이 없다고 적는다(약정서의 일반 조항과 상품설명서가 다르다). P2와 P4가 요약과 답이 서로 다르다며 가장 크게 헷갈려 했다. 토스뱅크 줄은 "확인 필요"를 달았지만 카카오뱅크 줄은 달지 않았다.
2. **'물어보기 →'가 거의 안 보인다.** 5명 중 4명이 봤지만 누르지 않았고 1명은 못 봤다. 1차 의견을 반영해 줄마다 달았지만, 화면이 복잡하다는 의견으로 흐린 회색으로 바꾼 뒤 눈에 띄지 않게 됐다.
3. **'판단할 수 없음' 다음에 할 일이 없다.** 4명이 "믿음도 가지만 답답하다"고 했다. P1: "그럼 앱이나 고객센터에서 뭘 확인하면 되는지 한 줄로 알려 주면 좋겠다."
4. **결론이 늦게 나온다.** P3: "내 경우는 괜찮다/조심해야 한다를 맨 위에 한 줄로." 분류기 오탐으로 붙은 '단정할 수 없어요' 문장이 결론을 더 뒤로 민다.
5. **답 품질**: 근거 없는 답이 그대로 나간다. 신용대출 질문에 주택담보 조건을 섞는다. 질문의 두 번째 물음을 놓친다.
6. **연대보증인 관점이 없다.** 요약 6줄이 모두 차주 기준이라 P5는 어디를 봐야 할지 몰랐다.

## 고칠 것 (제안 순서)

1. 카카오뱅크 중도상환해약금 요약 줄 수정(+ 요약 전체를 상품설명서와 다시 대조)
2. 근거 0개인 답에는 "확인 필요"를 붙이는 안전장치, 신용대출 질문에 주택담보 조건을 앞세우지 않게 점검 지시 보강
3. '물어보기 →'를 다시 보이게(흐린 회색 → 강조색 작은 버튼)
4. '판단할 수 없음' 답 끝에 "은행에 이렇게 물어보세요" 한 줄
5. 결론 한 줄 먼저(답 형식)
6. 연대보증인 질문용 예시 질문 추가

실제 사람 테스트는 위를 고친 뒤 대출 경험자 위주로 다시 한다.
