# 데이터 원칙과 리스크

공개 자료만 쓰고, 범위는 작게 유지한다.

## 데이터 원칙

- 약관과 상품설명서는 **금융사와 공시 기관이 공개한 자료**에서만 수집한다.
- 업무상 알게 된 비공개 자료, 고객 데이터, 개인정보는 사용하지 않는다.
- 사용자 인터뷰는 동의를 받고, 기록에는 이름과 식별 정보를 남기지 않는다.
- 앱 관찰 스크린샷에는 개인정보가 보이지 않게 한다. 대출 한도 조회처럼 동의 절차가 있는 단계 전까지만 관찰한다.
- 수집한 자료의 출처와 수집 날짜를 함께 기록한다.

## 고지

fineprint는 학습과 연구를 위한 개인 프로젝트다. 결과물은 금융 자문이나 상품 권유가 아니다.

## 리스크와 대응

| 리스크 | 대응 |
|---|---|
| 금융사 내부 사정을 아는 척하기 | "공개 자료로 파악한 범위에서는"이라는 전제를 명시한다 |
| 에이전트 기술 자랑으로 흐르기 | 주인공은 사용자와 금융사의 문제다. 파이프라인은 조연이다 |
| AI가 쓴 티가 나는 분석 | 직접 관찰, 인터뷰 같은 1차 정보를 반드시 넣는다 |
| 오래된 약관으로 잘못 해석 | 약관 버전과 수집 날짜를 기록하고, 답에 기준 날짜를 표시한다 |
| 범위가 커져서 지침 | 한 사이클에 상품 하나만 다룬다 |
