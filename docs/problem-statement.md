# 문제 정의 (1페이지)

- **작성**: 전채아, 2026-10-08
- **범위**: 사이클 1, 신용대출
- **근거**: [앱 관찰](../research/app-observation.md) · [설문 39명](../research/survey-results.md) · [공시 약관 11개](../research/terms-sources.md) · [D-008](decision-log.md)

## 한 문장

> 신용대출을 받는 사람은 **나에게 불리할 수 있는 조건**을 동의 전에 알지 못한다. 약관은 다 공개돼 있지만 너무 길고, 앱의 요약은 눈에 남지 않으며, 불리한 조건을 내 상황에 맞춰 짚어 주는 곳이 없다.

## 누구의, 어떤 순간의 문제인가

- **사람**: 앱으로 신용대출을 알아보거나 받는 사람. 설문 응답자의 64%가 최근 3년 안에 대출을 받거나 알아봤다.
- **순간**: 한도와 금리를 확인한 뒤, "필수 동의하기" 버튼을 누르기 직전. 이때 133쪽, 217쪽짜리 동의서가 함께 지나간다.

## 무엇이 문제인가 (근거 셋)

| | 보이는 것 | 근거 |
|---|---|---|
| **읽지 않는다** | 85%가 약관을 거의 읽지 않는다. 이유는 "너무 길다"(92%), "어차피 동의해야 넘어간다"(59%) | 설문 |
| | 동의는 버튼 하나다. 133쪽 약관도 몇십 초 만에 넘기고 동의할 수 있었다 | 앱 관찰 |
| **요약은 있어도 남지 않는다** | 일부 앱은 법정 설명 항목을 요약 카드로 잘 보여 준다. 하지만 대출을 알아본 사람의 52%는 그 요약 화면을 기억하지 못한다 | 앱 관찰, 설문 |
| **당황하는 건 숫자가 아닌 조건이다** | 금리(79%)와 한도(72%)는 다들 확인한다. 나중에 당황한 건 금리가 오르는 조건, 중도상환수수료, 신용점수 영향, 만기 연장 조건이다. 51%가 이런 경험이 있다 | 설문 |
| | 예: "자동 연장인 줄 알았는데 재연장 심사가 있었다." 실제로 토스뱅크·카카오뱅크 약정서에는 은행 심사와 연장 약정을 거쳐야 연장된다고 적혀 있다 | 설문, 약관 원문 |

## 왜 지금의 해법으로는 안 되는가

1. **요약 카드**: 법이 정한 항목을 모두에게 같은 순서로 보여 준다. "내 경우에는 어떻게 되나"에 답하지 않고, 기억에도 잘 남지 않는다.
2. **"이해했어요" 버튼**: 이해를 확인하지 않는다. 자기 신고일 뿐이다.
3. **약관을 일반 AI에 넣어 요약하기**: 실제로 그렇게 하는 응답자도 있었다. 하지만 근거를 대지 않으면 믿을 수 없고, 틀려도 알 수 없다. 사람들은 AI를 믿으려면 **조항 원문**(59%)과 **"모르면 모른다"**(38%)가 필요하다고 답했다.
4. **약관 원문을 그대로 믿기도 어렵다.** 같은 내용도 은행마다 조 번호가 다르고(대출계약 철회: 토스뱅크 제14조, 카카오뱅크 제13조, 하나은행 제4조의2), 한 은행의 약정서가 기본약관의 다른 조를 가리키는 것으로 보이는 곳도 있었다([사례](../research/terms-sources.md#원문을-나눠-보고-알게-된-것)). 근거를 "제○조"만 달아서는 부족하고, 참조가 맞는지도 확인해야 한다.

## 그래서 무엇을 만드나 ([D-008](decision-log.md))

1. **불리할 수 있는 조건 요약**: 약관 하나에서 금리 인상 조건, 중도상환수수료, 연체·기한이익상실, 신용점수 영향, 만기 연장 조건을 5~7줄로 보여 준다. 줄마다 은행·문서·버전·조항과 원문을 붙인다. 끝에 가벼운 이해 확인 질문 하나를 둔다.
2. **조항 근거 답변**: "1년 안에 갚으면 얼마를 내나요?"처럼 내 상황을 물으면 해당 조항을 찾아 답한다. 근거가 없거나 참조가 맞지 않으면 판단할 수 없다고 말한다.

**이번에 하지 않는 것**: 금융사 간 비교, 상품 추천, 개인 신용정보 연동, 신용대출 외 상품.

## 성공을 어떻게 알 것인가

| 구분 | 지표 | 목표 (가설) |
|---|---|---|
| 신뢰 | 인용 정확도: 답의 근거 조항이 실제로 맞는 비율 | 90% 이상 |
| 신뢰 | 판단 불가 응답률: 약관으로 답할 수 없는 질문에 "판단 불가"라고 답한 비율 | 90% 이상 |
| 신뢰 | 권유 표현 | 0건 |
| 사용자 가치 | 불리한 조건 이해도: 같은 약관을 원문만 본 사람과 fineprint를 본 사람이 핵심 조건 5개 중 몇 개를 맞히는지 | fineprint 쪽이 더 높다 |
| 사용자 가치 | 질문 사용률: 요약을 본 뒤 직접 질문하는 비율 | 낮으면 D-008을 다시 본다 |

목표 수치는 아직 근거가 없는 출발점이다. 1차 평가 뒤에 고친다.

## 기업용으로 이어지는 지점

같은 문제가 금융사 쪽에서는 **설명의무**다. 상담원이 불리한 조건을 빠뜨리면 불완전판매 위험이 생긴다. 소비자용 코어(불리한 조건 추출, 조항 근거, 이해 확인)를 그대로 써서 "설명해야 할 항목 체크리스트와 누락 점검"으로 바꾼다. 설문에서 대출 경험이 없는 사람들이 이해 확인을 많이 고른 것도 이쪽 근거다.

## 가정과 위험

- **표본**: 설문 39명은 지인 경로이고, 신용대출을 알아본 사람은 11명이다. 방향 확인용이지 일반화가 아니다.
- **문서 범위**: 하나은행은 가계용 대출거래약정서가 공개돼 있지 않아 약정서 층이 비어 있다.
- **약관 변경**: 약관은 자주 바뀐다. 답에는 문서 버전과 기준 날짜를 함께 보여 준다.
- **법적 경계**: fineprint의 답은 금융 자문이 아니다. 해석이 갈리는 조항은 판단 불가로 둔다.
