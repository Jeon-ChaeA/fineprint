# 로드맵

## 사이클 1: 신용대출 (3주)

범위를 신용대출 하나로 좁혀 3주 안에 두 결과물까지 끝낸다.

### 1주차: 문제 정의

- [x] 금융 앱 여러 곳에서 신용대출 조회부터 약관 확인 직전까지 직접 들어가 보고 기록
  - 약관과 상품설명서가 어디에, 몇 번 눌러야 나오는가
  - 중도상환수수료, 금리 변동 조건이 요약돼 보이는가, 원문을 열어야 하는가
  - 읽다가 "이게 무슨 뜻이지?" 싶었던 부분
- [x] 익명 사용자 설문 만들고 공개 (인터뷰 대신, D-007)
- [ ] 설문 응답 20건 이상 모으고 결과 정리
- [ ] 공시 약관 수집처 확인
- [ ] 문제 정의 1페이지 작성

산출물: 문제 정의 1페이지, 관찰 기록, 설문 결과

### 2주차: 코어 구축

- [ ] 공시 약관 수집
- [ ] 조항 단위 분할과 조항 번호 부여
- [ ] 근거 인용 에이전트
- [ ] 평가 질문셋 작성과 1차 평가
- [ ] 소비자용 화면 프로토타입

산출물: 동작하는 프로토타입, 평가 질문셋, 1차 평가 결과

### 3주차: 두 쓰임새로 패키징

- [ ] 소비자용 PRD: 문제, 해결안, 성과 지표, 실험 설계
- [ ] 기업용 도입 제안서: 현행 업무 분석, 아키텍처, 보안 요건, 기대 효과
- [ ] 빌드 로그 정리와 회고

산출물: PRD, 도입 제안서, 빌드 로그

## 이후 사이클 (후보)

- 신용카드: 혜택 조건과 제외 항목 해석
- 보험: 면책 조항, 보장 제외, 해지환급금. 난이도가 가장 높아 코어가 안정된 뒤에 다룬다.
- 상품 간 비교 기능 고도화
