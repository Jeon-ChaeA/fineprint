# 로드맵

## 사이클 1: 신용대출 (3주)

범위를 신용대출 하나로 좁혀 3주 안에 두 결과물까지 끝낸다.

### 1주차: 문제 정의

- [x] 금융 앱 여러 곳에서 신용대출 조회부터 약관 확인 직전까지 직접 들어가 보고 기록
  - 약관과 상품설명서가 어디에, 몇 번 눌러야 나오는가
  - 중도상환수수료, 금리 변동 조건이 요약돼 보이는가, 원문을 열어야 하는가
  - 읽다가 "이게 무슨 뜻이지?" 싶었던 부분
- [x] 익명 사용자 설문 만들고 공개 (인터뷰 대신, D-007)
- [x] 설문 응답 20건 이상 모으고 결과 정리 (39건, [결과](../research/survey-results.md))
- [x] 설문 결과로 방향 결정 (D-008, 39건으로 재검토해 유지)
- [x] 공시 약관 수집처 확인 ([수집처](../research/terms-sources.md))
- [x] 문제 정의 1페이지 작성 ([problem-statement.md](problem-statement.md))

산출물: 문제 정의 1페이지, 관찰 기록, 설문 결과

### 2주차: 코어 구축

- [x] 공시 약관 수집 (은행 3곳, 문서 11개, [sources.json](../data/sources.json))
- [x] 조항 단위 분할과 조항 번호 부여 (1차, [parse_terms.py](../scripts/parse_terms.py))
- [x] 근거 인용 에이전트 1차 (검색 → 근거 묶기 → 교차 참조 확인 → 답 → 인용 검증, [agent.py](../fineprint/agent.py))
- [x] 평가 질문셋 작성 (32문항, [eval/](../eval/README.md))
- [x] 1차 평가 (인용 정확도 100%, 답 정확도 75%(전채아 확인), [결과](../eval/results-v1.md))
- [x] 에이전트 1.1: 층별 검색, 짧은 문서 통째로, 참조 따라가기, 프롬프트 보강 (답 정확도 75% → 88%, 새 문항 50% → 70%, [결과](../eval/results-v1.1.md))
- [ ] 에이전트 1.2: 답 점검 단계(빠진 예외·결과 보충), 비슷한 제도 구분
- [ ] 소비자용 화면 프로토타입: 불리한 조건 요약 + 조항 근거 답변 (D-008)

산출물: 동작하는 프로토타입, 평가 질문셋, 1차 평가 결과
