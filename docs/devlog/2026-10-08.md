- 나눠 보니 같은 내용도 은행마다 조 번호가 달랐다(대출계약 철회: 토스 제14조, 카카오 제13조, 하나 제4조의2). 인용에는 은행, 문서, 버전이 꼭 붙어야 한다.
- 설문의 "만기 재연장 심사" 사례가 토스·카카오 약정서에 그대로 있었다. 평가 문항 후보로 둔다.
- 토스뱅크 약정서 제12조가 상계 근거로 기본약관 "제10조"를 가리키는데, 기본약관의 상계는 제11조다. 확인이 필요하지만, 교차 참조를 그대로 믿으면 안 된다는 예시로 기록했다. ([수집처 문서](../../research/terms-sources.md#원문을-나눠-보고-알게-된-것))
- 앱 관찰, 설문, 약관 원문을 묶어 [문제 정의 1페이지](../problem-statement.md)를 썼다. 1주차 산출물이 모두 나왔다.
- 교차 참조 불일치는 이렇게 다루기로 했다: 수집처 문서에 사실만 적고 "확인 필요"로 둔다. 데이터 원칙에 같은 규칙을 넣고, 설계 원칙에는 교차 참조 검증과 "원문 자체가 함정인 평가 문항"으로 반영했다. 은행에는 따로 문의하지 않는다.
- 평가 질문셋 32문항을 만들었다. ([eval/](../../eval/README.md)) 설문에서 당황한 조건(금리 인상, 중도상환, 연체, 신용점수, 만기 연장)을 중심으로, 판단 불가 3문항, 교차 참조 함정 1문항, 권유 유도 1문항을 넣었다.
- 문항마다 정답 근거를 은행·문서·버전·조항까지 적고, 원문에 실제로 있는 짧은 문구(evidence)를 붙였다. [scripts/check_eval.py](../../scripts/check_eval.py)로 확인하니 처음에 2문항이 걸렸다. 하나는 근거 문구를 다른 조항 제목에서 가져왔고, 하나는 카카오뱅크 제2조 제5항의 실제 문장과 달랐다. 고친 뒤 32문항 모두 통과했다.
- 문항을 만들다 보니 토스뱅크 문서에서 상계를 "기본약관 제10조"로 가리키는 곳이 4곳이었다. 일관된 번호라 개정 뒤 반영이 안 됐을 가능성이 있다고 추정만 적었다.

## 달라진 것과 그대로인 것

- **그대로**: 85%가 거의 안 읽는다. 51%가 요약 화면을 기억하지 못한다. 대출을 받아 본 사람의 1위는 여전히 조항 근거 답변이다.
- **달라짐**: 하나만 고르면 요약이 32% → 28%로 줄고, 이해 확인이 19% → 21%로 근거 답변과 공동 2위가 됐다. 새 응답 8건 중 5건이 대출 경험이 없는 사람이었고, 이 그룹에서 이해 확인을 많이 골랐다.
- **새로 나온 사례**: "자동 연장인 줄 알았는데 만기 때 재연장 심사가 있었다." 신용대출과 마이너스통장에서 흔한 조건이라 요약 대상에 넣었다.

## 판단

- 순서가 크게 바뀌지 않았고, 대출 경험자의 선택도 같아서 방향은 유지했다.
- 이해 확인은 버리지 않는다. 소비자용 화면에서는 요약 끝에 가벼운 확인 질문 하나를 붙여 반응을 보고, 본격적으로는 기업용(설명의무) 제안서에서 다룬다.

## 사람이 판단한 지점

- 평가 질문셋은 AI가 원문을 읽고 초안을 만들었다. 전채아는 정답 확인을 AI 검증 3회로 대신하기로 정했다(자동 검사 → 독립 AI 검토자 3명 → 수정본 재검토). 19문항의 정답을 고쳤고(인용만 정리한 문항까지 26개), 대부분 빠진 예외를 채운 것이었다. 자세한 내용은 [검증 기록](../../eval/README.md#검증-기록).
- 문제 정의 작성과 교차 참조 사례를 어디에 기록할지는 AI에게 맡겼다. AI는 사실만 적고 단정하지 않는 쪽으로 정했다.
- 3번째 은행을 하나은행으로, 원문 PDF를 로컬에 받는 것을 직접 정했다.
- 40건 근처에서 다시 집계하자는 시점은 직접 정했다.
- 재집계, 비교표, 문서 수정은 AI가 했다. D-008 유지와 만기 연장 조건 추가는 결과를 보고 함께 정했다.

## 정답 검증에서 배운 것

- AI가 만든 정답의 약점은 숫자보다 **빠진 예외**였다. "7영업일 전 통지"는 맞지만 3천만원 미만이면 10영업일이 된다. 코어도 같은 실수를 할 것이므로, 답을 만들 때 같은 조의 다른 항과 단서를 함께 읽게 해야 한다.
- 토스뱅크 질문에 카카오뱅크 문서를 근거로 단 곳이 있었다. 두 은행은 금리인하요구 결과 통지 시점이 달라 실제로 답이 달라진다. 인용은 질문한 은행 문서로만 채점하도록 바꿨다.
- 교차 참조가 맞지 않아 보이는 곳을 두 곳 더 찾았다([공시 약관 수집처 5번](../../research/terms-sources.md#원문을-나눠-보고-알게-된-것)).
