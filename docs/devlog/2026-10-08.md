## 달라진 것과 그대로인 것

- **그대로**: 85%가 거의 안 읽는다. 51%가 요약 화면을 기억하지 못한다. 대출을 받아 본 사람의 1위는 여전히 조항 근거 답변이다.
- **달라짐**: 하나만 고르면 요약이 32% → 28%로 줄고, 이해 확인이 19% → 21%로 근거 답변과 공동 2위가 됐다. 새 응답 8건 중 5건이 대출 경험이 없는 사람이었고, 이 그룹에서 이해 확인을 많이 골랐다.
- **새로 나온 사례**: "자동 연장인 줄 알았는데 만기 때 재연장 심사가 있었다." 신용대출과 마이너스통장에서 흔한 조건이라 요약 대상에 넣었다.

## 판단

- 순서가 크게 바뀌지 않았고, 대출 경험자의 선택도 같아서 방향은 유지했다.
- 이해 확인은 버리지 않는다. 소비자용 화면에서는 요약 끝에 가벼운 확인 질문 하나를 붙여 반응을 보고, 본격적으로는 기업용(설명의무) 제안서에서 다룬다.

## 사람이 판단한 지점
