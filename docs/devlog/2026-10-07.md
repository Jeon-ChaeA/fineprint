# 2026-10-07: 앱 관찰, 설문, 방향 결정

## 오늘 한 일

### 오전: 앱 관찰

- 금융 앱 4곳(토스, 카카오뱅크, 하나은행, 현대카드)에서 신용대출 화면을 화면 녹화로 관찰했다.
- 녹화 영상을 1초 단위 프레임으로 나눠 AI가 1차 정리하고, 앱별 비교표를 만들었다. ([앱 관찰 기록](../../research/app-observation.md))
- 관찰 결과로 문제 정의를 2차로 다시 썼다. ([background.md](../background.md))

### 오후: 사용자 설문 만들고 공개

- 관찰에서 나온 가설을 검증할 6단계, 5분짜리 설문을 만들었다. ([설문 페이지](https://fineprint-survey.netlify.app/))
- 응답은 Google Apps Script 웹 앱을 거쳐 비공개 Google 스프레드시트에 저장된다. ([설계와 설정](../../research/survey/README.md))
- 실제 공개 주소에서 끝까지 제출해 보고 시트에 저장되는 것을 확인한 뒤, 테스트 응답은 지웠다.
- 설문을 돌릴 때 쓸 홍보 문구를 정리했다. ([홍보 문구](../../research/survey/outreach-message.md))

### 저녁: 설문 결과와 방향 결정

- 공개 후 약 3시간 만에 31건이 모였다. 목표였던 20건을 넘겨 바로 집계했다. ([설문 결과](../../research/survey-results.md))
- 집계는 응답 시트 안에서 돌리고 숫자만 가져왔다. 응답 원본은 레포에 올리지 않았다.
- 결과로 방향을 정했다: **근거가 붙은 불리한 조건 요약 + 조항 근거 답변** ([D-008](../decision-log.md))

## 가장 놀란 것

- 한 번의 대출 조회에 **133쪽**, **217쪽**짜리 동의서가 따라온다. 휴대폰에서는 확대하지 않으면 글자가 안 보인다.
- 133쪽 약관도 몇십 초 만에 끝까지 넘기고 동의할 수 있었다.
- 같은 "중도상환수수료 없음"이 앱마다 전혀 다른 무게로 보인다.

## 생각이 바뀐 지점

- 처음에는 "약관을 요약해 주는 AI"를 생각했다. 그런데 일부 금융사는 이미 법정 설명 항목을 요약 카드로 잘 보여 주고 있었다.
- 그래서 요약보다 **요약 카드에 없는 조항을 근거와 함께 찾아 주기**, **금융사 간 비교**, **이해 확인** 쪽이 fineprint의 빈틈이라고 보게 됐다.
- 설문에서 한 번 더 바뀌었다. 요약 수요가 1위였다(하나만 고르면 32%). "요약은 이미 있다"는 관찰과 부딪히는 결과다.
- 그런데 대출을 알아본 사람의 55%는 앱의 요약 화면을 기억하지 못했다. 요약이 없는 게 아니라 눈에 남지 않는 것이다. 그래서 요약을 버리지 않고, **불리한 조건만 골라 줄마다 조항 근거를 붙이는 요약**으로 바꿨다.
- 대출을 실제로 받아 본 사람들은 요약보다 조항 근거 답변을 더 많이 골랐다. 비교와 이해 확인은 뒤로 미뤄다. ([D-008](../decision-log.md))

## 설문을 만들며 내린 결정

| 결정 | 이유 |
|---|---|
| Google 폼 대신 직접 만든 HTML 페이지 | fineprint의 "약관 종이" 콘셉트로 디자인하고, 레포와 같은 주소에 두려고 |
| GitHub Pages + Apps Script + 스프레드시트 | 서버 없이 무료로, 링크만 있으면 누구나 응답할 수 있게 |
| 인터뷰 대신 익명 설문, 연락처 문항 삭제 ([D-007](../decision-log.md#d-007-사용자-조사는-익명-설문으로-한다)) | 개인정보를 아예 받지 않아 응답을 완전히 익명으로 만들기 위해 |
| 시트 ID는 레포에 올리지 않음 | 공개 레포에는 `YOUR_SHEET_ID` 자리만 남김 |

## 막혔던 것

- 설문 주소가 처음에 404였다. GitHub Pages가 아직 꺼져 있었기 때문이다. Settings → Pages에서 main 브랜치로 켜자 해결됐다.
- 스프레드시트의 시간이 미국 시간대로 찍혔다. 시트 시간대를 서울로 바꿨다.
- 일부 PC 환경에서 `github.io` 주소가 `ERR_CONNECTION_TIMED_OUT`으로 열리지 않았다. 네트워크 차단으로 보고, 같은 페이지를 Netlify(https://fineprint-survey.netlify.app/)에도 올려 기본 링크로 바꿨다.

## 사람이 판단한 지점

- 영상 분석과 표 정리, 설문 페이지와 수집 스크립트 작성은 AI가 했다.
- 무엇이 "놀라운 발견"인지, 방향 전환을 언제 결정할지, 어떤 문항을 뺄지는 직접 판단했다.
- 설문 집계와 결과 문서 초안은 AI가 했다. 20건이 넘자 바로 집계하고 방향을 정하기로 한 것은 직접 판단했다.
- Google 로그인과 권한 승인은 직접 했다.
- 영상에 이름, 계좌, 개인화된 한도·금리가 찍혀 있어서 원본 영상과 캡처는 레포에 올리지 않기로 했다.
