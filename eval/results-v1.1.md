## 무엇을 바꿨나

| 바꾼 것 | 왜 (1차 평가에서 본 것) |
|---|---|
| **층별 검색**: 기본약관·약정서·설명서에서 각각 상위 4개 단위(조 또는 쪽)를 가져와 점수순으로 합친다 | 긴 설명서가 근거 자리를 다 차지해 다른 층의 예외 조항을 놓쳤다(Q11, Q18, Q23) |
| **단위로 세기**: 설명서 한 쪽이 여러 조각으로 나뉘어도 한 단위로 센다 | 같은 쪽 조각들이 자리를 독차지했다 |
| **짧은 문서는 통째로**: 3,000자 이하 문서는 한 조각만 걸려도 전부 넣는다 | 추가약정서의 목적 조항만 가져오고 의무 조항을 놓쳤다(Q25) |
| **참조 따라가기**: 약정서·설명서가 "기본약관 제N조"를 가리키면 그 조를 바로 뒤에 넣는다 | 만기 미상환 시 상계 근거(기본약관 제11조)를 못 가져왔다(Q23) |
| **수집한 문서 목록을 함께 준다** + 프롬프트 규칙 2개 | 질문한 문서가 없을 때 "확인 필요"를 쓰지 않았다(Q31). 거절·미이행 뒤 결과를 빠뜨렸다(Q22, Q23) |

검색 개선은 근거 재현율로 먼저 확인했다(LLM 없이). 기존 문항 82% → 94%, 새 문항 68% → 91%.

## 아직 남은 것 (2026-10-08 기준 감점 7건, 기준 변경 뒤 Q32·H02가 더해짐)

| 원인 | 문항 | 내용 |
|---|---|---|
| **근거는 있는데 답에서 빠뜨림** | Q11, Q25, H01, H03, H07 | 절차·결과·숫자가 근거 목록에 있었지만 답에 쓰지 않았다. 예: 위반 시 서면 독촉 후 10일(Q25, H07), 새로 내는 인지세 7만원(H01) |
| **비슷한 제도를 섞음** | Q16 | 개인채무자보호법의 채무조정 요청과 설명서의 채무조정요청권(실직·질병 사유)을 같은 제도처럼 썼다. 1.0에서는 맞았던 문항이다. 근거가 늘어나면서 생긴 부작용으로 본다 |
| **원문 표현을 잘못 옮김** | Q13 | "이자를 지급하여야 할 때부터"를 "이자를 낸 날부터"로 썼다 |

1.0에서는 감점의 절반이 검색 탓이었다. 1.1에서는 대부분 **답을 쓰는 단계**에서 생긴다. 근거는 거의 다 가져오므로, 다음 개선은 답 쓰기 쪽이다.

## 비용

근거 목록이 약 2.4배 길어졌다(평균 약 4,800자 → 11,200자). 답 정확도가 오른 만큼 입력 토큰도 늘었다. 지금 규모(문서 11개)에서는 문제가 없지만, 상품이 늘면 근거 목록 상한(26조각)과 층별 개수를 다시 정한다.

1. **답 점검 단계**: 답을 쓴 뒤 "근거 목록에 있는 예외·결과·숫자 중 답에 빠진 것"을 한 번 더 확인해 보충한다(감점 5건)
2. **제도 구분**: 이름이 비슷한 제도(채무조정 요청 / 채무조정요청권 등)가 함께 나오면 근거를 나눠 쓰게 한다(Q16)

## 2026-10-14 채점 기준 변경 (전채아 채점 피드백)

전채아가 1.1 채점지를 직접 채점하며 기준을 바로잡았다. 모든 버전·질문셋에 같이 적용하고 숫자를 다시 셌다.

1. **필수·선택 통일**: 정답 요지에 있는데 답에서 빠져도 O가 되던 문항이 있었다. 질문이 직접 묻는 것만 필수로 남기고 나머지는 '선택 요소'로 옮겼다(Q02 우대 적용기간, Q03 조건변경·우대, Q09 추가약정서, Q23 지연배상금 시작일, Q31 연장 후 금리). 남긴 필수가 빠지면 △다.
2. **현재 적용 여부는 필수**: Q25(고액 신용대출 추가약정)와 Q32(은행 비교)는 '수집한 문서 기준이며 현재 적용 여부는 확인 필요'를 밝혀야 O다. 지금까지 어느 버전도 밝히지 않아 모두 △가 됐다.
3. **H02 O → △** (1.1): 기한이익 상실 요건 중 '은행의 채권보전에 현저한 위험'과 '객관적으로 적정한 조치 없이 기간 경과'가 빠졌다.
4. **자동 검사**: '확인 필요'만 찾던 것을 '확인이 필요합니다'도 인정하게 고쳤다(1.0의 H10이 통과로 바뀜).
5. **지표 이름**: '인용 정밀도'는 같은 은행 문서면 관련 없는 조항도 통과하므로, 계산은 그대로 두고 '질문 은행 일치율'로 이름을 바꿨다.
