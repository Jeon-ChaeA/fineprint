# 신용카드 검색 평가 1차 (사이클 2, 2026-11-04)

- **대상**: 하나카드 MOVING카드와 신세계 BC 바로 클리어 플러스 문서(`data/sources-card.json`), 검색 코어 카드 모드(`Agent(product="card")`)
- **질문셋**: [credit-card-holdout-v1.jsonl](credit-card-holdout-v1.jsonl), 24문항(하나카드 12, BC카드 12, 판단 불가 3). 카드 용어 사전과 검색 규칙을 보지 않은 별도 에이전트(Sonnet)가 문서만 읽고 썼다. 문항마다 정답 문장이 있는 위치와, 그 위치에 글자 그대로 있는 문구(`evidence`)를 달았고 24개 모두 원문 대조를 통과했다.
- **잰 것**: 답을 쓰지 않고 **검색만** 쟀다(모델 호출 없음). 정답 문구가 들어 있는 조각이 근거 목록에 들어오는가.
- **사이클 2를 가볍게 끝내기로 해서**(전채아 결정) 답 품질 평가(모델 답 + 채점)는 하지 않았다.

## 결과

| 측정 | 카드 용어 사전 있음 | 사전 없음 |
|---|---|---|
| 근거 목록(평균 30조각)에 정답 문구가 들어옴 | **23/24** | 23/24 |
| 층별 검색 상위 5개 안 | 14/24 | 14/24 |
| 층별 검색 상위 10개 안 | 19/24 | 19/24 |

- **근거 목록 재현율은 높지만 순위는 낮다.** 근거 목록에 30조각까지 담아서 23/24가 들어오지만, 상위 5개 안에 드는 건 14개다. 무료 모델(flash-lite)은 근거가 많을수록 요소를 빠뜨렸으므로(사이클 1), 순위가 낮은 근거는 답에서 빠질 수 있다.
- **카드 용어 사전은 처음 보는 질문에서 효과가 없었다.** 사전을 만들 때 직접 쓴 점검 질문 8개에서는 순위가 올랐지만(전월 실적 14위 → 6위 등, [수집 기록](../research/card-terms-sources.md)), 사전을 모르는 사람이 쓴 24문항에서는 상위 5·10개 수가 같았다. 문항별로는 사전 없음 → 있음으로 오른 것(C06 11위→2위, C14 16위→8위)과 내려간 것(C08 15위→20위 밖, C24 8위→20위)이 섞여 상쇄됐다. 사이클 1의 교훈(규칙을 만든 질문으로 재면 효과를 착각한다)이 그대로 나왔다.
- **놓친 1문항 (C02)**: "새로 발급받았는데 첫 달부터 50만원 못 쓰면 혜택 못 받나요?" 정답은 MOVING카드 9쪽 "최초카드 사용등록일부터 다음달 말일까지는 지난달 카드 실적 50만원 미만이어도"다. 질문의 "새로 발급", "첫 달"과 원문의 "최초카드 사용등록일"이 이어지지 않았다.
  - **이 질문셋으로는 고치지 않는다.** 고치면 더 이상 처음 보는 질문이 아니다. 다음에 고칠 때는 새 질문셋을 먼저 만든다.

## 판단

- 카드 문서에서도 검색 코어는 그대로 동작한다(근거 목록 23/24). 사이클 1의 코어를 바꾸지 않고 문서 분할(표·좌우 면)과 카드사 이름만 더해 붙었다.
- 순위(상위 5개 14/24)는 개선 여지가 있다. 용어 사전을 늘리는 방식은 처음 보는 질문에서 효과가 확인되지 않았으므로, 다음에 한다면 설명서 층 가중치나 질문 분류(실적/한도/연회비…)별 쪽 지정 같은 다른 방법을 처음 보는 질문셋으로 비교한다.
