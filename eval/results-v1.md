## 어떻게 돌렸나

| 단계 | 하는 일 | 누가 |
|---|---|---|
| 1. 검색 | 한글 2글자 단위 BM25 + 용어 사전(사용자 말 → 약관 말). 질문 은행 문서에서 상위 8개 | 코드 ([retrieve.py](../fineprint/retrieve.py)) |
| 2. 근거 묶기 | 찾은 항과 같은 조의 다른 항을 함께 붙인다. 예외는 대개 같은 조의 다른 항에 있다 | 코드 |
| 3. 교차 참조 확인 | "기본약관 제N조"가 문맥(상계, 기한의 이익 등)과 맞는 조인지 제목으로 확인. 안 맞으면 경고와 함께 실제 조를 근거에 넣는다 | 코드 ([crossref.py](../fineprint/crossref.py)) |
| 4. 답 쓰기 | 근거 목록 [C1]… 안에서만 답하고, 문장마다 근거 번호를 단다. JSON으로 낸다 | LLM |
| 5. 인용 검증 | 답이 댄 번호가 실제로 준 근거인지 확인하고 은행·문서·버전·조로 바꾼다 | 코드 |

- 교차 참조 확인기는 전체 문서에서 경고 5건을 냈다. 기록해 둔 토스뱅크 상계 "제10조" 4곳과 설명서 철회 비용 "제13조" 1곳이고, 오탐은 없었다.
- **4단계의 LLM**: 이 작업 환경에는 API 키가 없어서, 같은 프롬프트를 Claude Sonnet에 주고 답을 받았다(프롬프트 파일 밖은 보지 못하게 했다). API 키가 있으면 `python scripts/run_eval.py generate`로 똑같이 다시 돌릴 수 있다.
- **답 정확도 채점**: AI 채점자가 먼저 채점하고, 전채아가 [grading.md](../runs/v1/grading.md)를 보고 확인했다. 고친 등급은 없다.

## 틀린 곳은 왜 틀렸나

| 원인 | 문항 | 무엇이 빠졌나 |
|---|---|---|
| **검색이 근거를 못 가져옴** | Q25 (X) | 고액 신용대출 추가약정서는 짧은 문서인데 제1조(목적)만 가져오고 제2조(주택 구입 금지)·제3조를 놓쳤다. 그래서 "근거에 없다"고 답했다 |
| | Q11, Q18, Q23 (△) | 기본약관 제13조②(전액 상환 요청 = 철회 의사 확인), 기본약관 제3조⑤(5천만원 미만 특례), 약정서 제3조②(만기 미상환 시 지연배상금)가 검색 결과에 없었다 |
| **근거는 있었는데 답에서 빠뜨림** | Q22, Q29, Q31 (△) | 연장 거절 시 전액 상환, 금리 결정 요소, 설명서의 연장 제한 조건 |
| **해석이 흐림** | Q09 (△) | 설명서의 "해약금 없음"과 일반 계산식을 상충으로 보고 결론을 내지 않았다 |
| **지표가 너무 문자 그대로** | Q31 | "약정서가 없어 판단할 수 없다"고 실질은 맞게 말했지만 "확인 필요"라는 말을 쓰지 않아 함정 탐지 실패로 셌다 |

검색만 따로 재면(정답 근거가 상위 8개 안에 드는가) 28/29로 높다. 하지만 이 지표는 **첫 번째 정답 근거**만 본다. 답을 완결하려면 두 번째, 세 번째 근거(다른 층 문서의 예외 조항)도 필요한데, 그걸 못 가져온 경우가 감점의 절반이었다.

## 다음 고칠 것 (1.1)

1. **짧은 문서는 통째로**: 조가 몇 개 안 되는 추가약정서는 한 조가 걸리면 문서 전체를 근거에 넣는다. (Q25)
2. **층별로 고르게 검색**: 기본약관·약정서·설명서에서 각각 상위 몇 개를 가져온다. 한 층(대개 설명서)이 근거 자리를 다 차지하지 않게 한다. (Q11, Q18, Q23)
3. **참조 따라가기**: 교차 참조 경고가 없어도, 근거가 "기본약관 제N조"를 가리키면 그 조를 함께 넣는다.
4. **프롬프트**: "그다음 어떻게 되나(결과)"와 "거절·미이행 시"를 꼭 답하게 하고, 질문한 문서가 수집 목록에 없으면 "확인 필요"를 쓰게 한다. 수집한 문서 목록을 근거와 함께 준다.
5. **검색 지표 보강**: 첫 번째 근거만이 아니라 정답 근거 전체를 얼마나 가져왔는지(재현율)를 함께 잰다.

고친 뒤 같은 32문항으로 다시 돌려 1차와 비교한다. 질문셋에 맞춰 고치는 것이 되지 않도록, 1.1에서는 새 문항 몇 개를 따로 만들어 함께 본다.
