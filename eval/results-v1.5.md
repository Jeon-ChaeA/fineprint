# 에이전트 1.5 평가 결과: 검색 보강 (2026-10-20)

- **목표**: 1.4에서 남은 감점 7문항 중 4~5문항은 근거 목록에 재료가 없어 생겼다(점검 단계는 없는 근거를 만들 수 없다). 그래서 검색을 고친다.
- **바꾼 것**: 답 쓰기(초안 + 점검 단계)는 1.4 그대로 두고 검색과 근거 묶기만 바꿨다([fineprint/agent.py](../fineprint/agent.py), [retrieve.py](../fineprint/retrieve.py)).

| 바꾼 것 | 왜 (1.4에서 본 것) |
|---|---|
| **같은 내용 조각 빼기**: 같은 문서에서 글자가 같은 조각은 하나만 넣는다 | 하나은행 설명서 1~3쪽과 4~6쪽이 같은 내용이라 같은 조각이 두 번씩 들어가 자리를 차지했다(H03) |

| **항까지 참조 따라가기**: "기본약관 제7조 제4항 제2호"는 제7조 ④를 정확히 넣는다. 통째로 넣은 짧은 문서(추가약정서)의 참조도 따라간다 | 조 단위로 앞 2개 항만 넣어 ④를 놓쳤다. 추가약정서는 검색에 걸린 조각이 아니라 참조를 따라가지 않았다(Q25) |

| **콕 집어 넣은 조각은 상한에서 자르지 않음**, 근거 상한 28 → 30조각 | 위 조각들이 목록 끝에 붙어 상한에서 잘렸다 |
| 용어 사전: 취소 → 대출취소, 신청만 → 대출신청 이후, 늘리 → 증액 | K01, H01 |

## 평가 방식 (비용 줄이기)

1. **근거 재현율 먼저**(LLM 없이): 다섯 질문셋 전체에서 정답 근거가 근거 목록에 들어갔는지 센다. 이번부터 **항 단위**로도 센다. 조 단위로만 세면 제7조 ①만 들어가도 ③을 맞힌 것으로 쳐서, 결과 조항을 놓친 것이 가려졌다.
2. **새 문항 4차(L01~L10)로 1회 비교**: [credit-loan-holdout-v4.jsonl](credit-loan-holdout-v4.jsonl). 1.5를 고치기 전에 만들었고, 다른 AI 검토자의 대조에서 경미 2건(L02 근거 추가와 표현 차이 메모, L09 연체이자율 근거 추가)을 고쳤다. 1.4와 1.5의 답을 A/B로만 표시해 한 채점자가 채점했다(블라인드).
3. 문항당 3회 평가는 하지 않았다. 버전을 최종 비교할 때만 한다.

| 질문셋 | 1.4 | **1.5** |
|---|---|---|
| 기존 32문항 | 75/83 (90%) | **83/83 (100%)** |
| 새 문항 1차 (H) | 18/22 (82%) | **22/22 (100%)** |
| 새 문항 2차 (J) | 18/19 (95%) | 18/19 (95%) |
| 새 문항 3차 (K) | 16/20 (80%) | **18/20 (90%)** |

| 근거 목록 크기 (문항 평균) | 약 29조각, 12,300자 | 약 31조각, 12,200자 |

- 1.4 감점의 원인이던 근거가 모두 들어온다: H01(세액표), H03(제11조 ②), H07·Q25(제7조 ③·④), K01(취소 비용).
- 조각 수는 조금 늘었지만 중복과 한 쪽 몰림을 뺀 덕분에 글자 수는 그대로다. 입력 비용은 늘지 않았다.

### 답 정확도: 새 문항 4차 (L, 1회, AI 블라인드, 전채아 확인 전 초벌)

| | 1.4 | **1.5** |
|---|---|---|
| O · △ · X | O 7 · △ 2 · X 1 | **O 8 · △ 2 · X 0** |
| 감점 문항 | L02 △, L06 X, L09 △ | L06 △, L08 △ |

- **L09 △ → O**: 만기 지난 대출의 연체이자(설명서 2쪽)를 1.5만 근거로 가져왔다.
- **L02 △ → O**: 1.4는 변동금리 변경이 '건전한 금융관행에 따라 합리적인 범위'여야 한다는 점(기본약관 제3조 ③)을 빠뜨렸다.
- **L06 X → △**: 두 버전 모두 "다른 금융사 연체정보 등록은 기한이익 상실 사유가 아니다"라고 잘못 답했다. 근거(카카오뱅크 기본약관 제7조 ③)를 두 버전 모두 못 가져왔다. 1.5는 독촉 절차를 덧붙여 △가 됐다.
- **L08 O → △**: 1.5가 연대보증인 파산을 알려야 하는지 결론을 유보했다. 정답 근거는 두 버전 모두 다 들어 있었으므로 검색이 아니라 **답 쓰기 흔들림**이다(1.4에서 같은 버전·같은 문항의 3회 등급이 갈린 비율이 약 19%였다).
- 자동 지표는 두 버전이 같다. 인용 정확도 100%, 함정 탐지 100%, 권유 0건, 지어낸 인용 0건. 판단 불가 응답률은 둘 다 1/2(L06을 판단 불가로 답하지 않음).
- 장황한 답 0개.

## 판단: 1.5 검색을 기본값으로 쓴다

- 근거 재현율이 다섯 질문셋 모두에서 같거나 올랐다(86% → 97%). 근거 목록 크기는 그대로다.
- 처음 보는 문항(L)에서 O 7 → 8, X 1 → 0. 1회 결과라 1문항 차이는 흔들림 범위 안이지만, 오른 두 문항(L02, L09)은 근거가 새로 들어와서 오른 것이라 우연으로 보지 않는다.
- 내려간 L08은 근거가 같은데 답이 달라진 경우다. 최종 비교 때 3회 평가로 다시 본다.
